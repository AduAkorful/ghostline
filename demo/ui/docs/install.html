01 / DOWNLOAD

One command to install.

The installer gets the latest Ghostline release, checks its SHA-256 checksum, and installs the three executables into ~/.local/bin.

INSTALL LATEST RELEASE
curl -fsSL https://raw.githubusercontent.com/AduAkorful/ghostline/main/scripts/install-ghostline.sh | sh

What gets installed

ghostline for channel operations, ghostline-paid-api for the reference service, and ghostline-mcp for MCP clients.

What the checksum means

It checks the downloaded archive against the release checksum file. It is not an independent publisher signature.

Required system tools: curl, tar, sha256sum, and awk. The current Ghostline v0.4.0 release includes the verified Linux x86-64 binaries. Use this command to install that version:

PIN GHOSTLINE v0.4.0
curl -fsSL https://raw.githubusercontent.com/AduAkorful/ghostline/main/scripts/install-ghostline.sh | GHOSTLINE_VERSION=v0.4.0 sh
Want to try it without a wallet? After the install, run ghostline demo --show-chain-evidence. It runs the local quote-and-pay flow and prints separate historical Esmeralda links; it does not use test funds or create a transaction. For a real testnet run, continue to the Esmeralda quickstart ↗.

02 / FIRST RUN

Check your PATH.

If your shell cannot find the installed commands, add the install directory to your PATH and check the CLI responds:

VERIFY THE INSTALL
export PATH="$HOME/.local/bin:$PATH"
ghostline --help
ghostline-paid-api --help

Add the PATH line to your shell startup file to keep it after reopening the terminal. Rerun the installer to update the executables. Keep wallet profiles and channel state in their own private directories.

03 / BEFORE A LIVE RUN

Bring your own setup.

Early development. Unaudited. Esmeralda testnet only. Do not use real funds.

Ghostline does not provide a hosted paid service, shared wallet, or default deployed template. To follow the quickstart, obtain deployment parameters from the provider and prepare:

  • A compatible Ootle wallet daemon connected to Esmeralda, kept on loopback.
  • A funded opener account for the channel deposit and opening fee, plus a funded service fee account.
  • The real indexer URL, network tag, deployed template hash, and service public key.
  • Your own private key storage, payer signing key, and wallet claim/view key.

Installation does not establish wallet compatibility or guarantee funding discovery. Review the fee estimate before opening, use integer µT values, and keep credentials and channel files private.

04 / BUILD FROM SOURCE

For contributors.

The verified development platform is Linux. Source builds require Rust from the repository's pinned toolchain, Git, a C/C++ toolchain, Clang with libclang, CMake, and protoc.

BUILD RELEASE EXECUTABLES
git clone https://github.com/AduAkorful/ghostline.git
cd ghostline
git checkout v0.4.0
cargo build --locked --release -p ghostline-cli -p ghostline-mcp -p ghostline-paid-api

Build channel WASM and publish a template separately. Never substitute an invented template or account identifier.
