    OPTIONAL · REAL ESMERALDA TESTNET

    Run it with your wallet.

    Live mode needs Sapient in this browser profile (or Tari Universe). After installing or enabling Sapient, reload this page before connecting. Live mode is a custodial testnet relay: it holds your 51 µT test deposit from funding until settlement, opens the channel, and settles or refunds it privately. The relay operator can see that deposit; on-chain observers see neither the deposit nor the split. Your voucher key never leaves your browser. The non-custodial path is the CLI, where your own wallet opens the channel. Use only test funds. Install Sapient ↗

    Before connecting: Use Sapient 0.7.1 or newer (update it from chrome://extensions). Switch it to Esmeralda. The deposit is 51 µT of private TARI. The wallet fee is paid from public TARI. Sapient shows a Max fee of 0.02 TARI; that is a cap, and the charge can be lower. Sapient 0.7.0 reports a private balance of 0 and rejects the send. A private-view prompt appears only when this site does not already have one.

    READ THE BOUNDARY
    The service sees each request, price, and voucher. Outside observers can still see transaction existence, fees, timing, branch, metadata, and commitments. A claim-free settlement hides the deposit and exact output amounts in public fields. This demo does not prove a call count on-chain.
